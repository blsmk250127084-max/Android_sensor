1. Motion Sensors (Sensor Gerak)
   Mengukur percepatan fisik pada 3 sumbu (X, Y, Z) termasuk gaya gravitasi. Digunakan untuk mendeteksi kemiringan, goyangan (shake), atau orientasi layar. 

2. Position Sensors (Sensor Posisi & Orientasi)
   Mendeteksi keberadaan objek (seperti telapak tangan atau telinga) yang mendekati layar bagian atas. Biasa digunakan untuk
   mematikan layar saat menerima telepon.

3. Environment Sensors (Sensor Lingkungan)
   Mengukur tingkat intensitas pencahayaan lingkungan sekitar dalam satuan Lux. Digunakan untuk penyesuaian otomatis
   kecerahan layar (Auto-Brightness) atau ubah tema (Day/Night).
